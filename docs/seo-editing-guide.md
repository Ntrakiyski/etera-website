# SEO & Social Sharing

Open Settings → SEO & Social Sharing in https://etera.trakiyski.work/admin.

1. Set the site name, default search title/description and title suffix. Existing SEO defaults are retained initially. Inner pages keep their page intro unless a search description is entered for that page.
2. Upload a default sharing image (1200 × 630 px recommended) and a square website icon (512 × 512 PNG recommended). Media Alt text describes the image. Blank selections keep the existing ETÉRA defaults.
3. Expand any of the seven page groups to set its search title/description and separate social title/description/image. Blank social fields inherit the search values; blank page images inherit the default sharing image.
4. Publish changes. Save Draft keeps the current public metadata. Primary website URL controls canonical, sharing, structured-data and sitemap URLs; leave blank for the deployed domain. Canonical overrides are advanced settings for duplicate pages.
5. Add a Google Search Console HTML verification token and optional @X/Twitter handle. Social profile URLs/contact/logo remain in Site Settings and are used in the Organization schema; site name/domain also appear in WebSite schema.

Disabling site indexing or selecting a page's Hide from search checkbox adds noindex and excludes affected pages from the sitemap. Public pages stay crawlable so engines can read noindex. These controls do not make pages private and removal from search can take time.

Google can rewrite titles/descriptions/icons and social platforms cache previews. Publishing updates the website's tags immediately; external preview refreshes and search appearance are controlled by those platforms. No ranking promise or meta-keywords field is included.
