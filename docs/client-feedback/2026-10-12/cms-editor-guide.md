# Editing the updated website

Open `/admin`. The controls below edit the shared content for desktop and mobile; responsive layouts are handled by the site, so images and text do not need duplicate mobile entries. Use Publish after saving approved changes. Saving a draft alone does not change the public site.

## Home introduction below the video

- Image: Pages → Home Page → Atelier Introduction — Image.
- Heading: Pages → The Atelier Page → Headline — Atelier hero and Home introduction.
- Description: Pages → The Atelier Page → Introduction — Atelier hero and Home introduction.
- Link: Pages → Home Page → Atelier Link Label.

The heading and description are intentionally shared between the Home introduction and Atelier hero. The image is independent of the Atelier story image. Desktop covers the taller column; mobile uses the approved 3:2 frame. Choose a photo whose subject has enough surrounding room for both crops.

## What We Do

- Home heading, introduction and link: Pages → Home Page → What We Do — Heading / Introduction / Link text.
- Category display titles: Pages → Services Page → Group Labels. Changes appear on both Home and Services.
- Entries inside each category: Content → Services → Name / Summary / Details.
- Category membership and order: Content → Services → Service category / Sort Order.

Changing a category's display title does not change its internal membership. Keep the Service category assignment when renaming the title in Group Labels.

## The Missing Element

- Image: Pages → The Atelier Page → The Missing Element — Image.
- Heading: Page text → Story Heading.
- Main paragraph: Aether Narrative.
- Additional paragraph: Page text → Story Additional.

This image does not replace the Home introduction image.

## Team

Pages → The Atelier Page → Team Members. Edit Name, Position, Description and Portrait in the matching person's row; use the person name rather than an uploaded filename to identify the portrait. Reorder the rows to change the display order. Use the approved final roles when supplied, with no guessed replacement titles.

## Method

- Heading and introduction: Pages → The Atelier Page → Page text → Method Heading / Method Intro.
- Wordmark: Method Logo.
- Titles, descriptions and order: Method — Steps → Step title / Step description.

A nonempty published description enables an expandable row. Without approved description text, the step is shown as a simple label. Proposed descriptions are in `method-copy-proposal.md`; they are not live copy.
