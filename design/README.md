# ETÉRA Design Folder

This folder is the working design source for the ETÉRA website. Use it before changing public UI.

## What Is Here

- `../PRODUCT.md`: durable product truth in the Impeccable product-context shape.
- `../DESIGN.md`: formal design system and machine-readable tokens.
- `tokens.css`: CSS token export for implementation.
- `tokens.json`: portable token export.
- `page-briefs.md`: page-by-page direction for Home, Work, The Atelier, Services, and Contact.
- `quality-checklist.md`: finish-pass checklist for avoiding generic AI-looking output.
- `impeccable-workflow.md`: how this repo uses the Impeccable method.
- `assets/brand/2026-08-24/`: Alexandra's final logo package and guideline.

## Working Rule

Before building or changing a public page, read `../PRODUCT.md`, `../DESIGN.md`, and the matching page brief. If a UI choice cannot be defended from those files or the client brief, it probably does not belong.

The goal is not to make a nice generic site. The goal is to make ETÉRA feel like ETÉRA.
